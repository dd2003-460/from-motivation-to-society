## 执行边界

1. 你是独立阶段门禁，不继承 Commander 主对话；只读取任务卡中的阶段输入包、契约和提交模板。
2. 检查 attribute_matrix 中每个调研字段是否带 evidence_refs，且 evidence 来自不同网页 LLM / 权威来源。
3. 检查矛盾/冲突字段是否已在 rationale 标注，且 disposition 已相应更新（必要时标 research_required 或降 confidence）。
4. 输出 pass、rollback 或 blocked_human；矛盾未消解不得 pass。
5. 参考阶段方法论（源自 loop/1-loop，补充要求，不覆盖上方门禁/边界规则）：
6. 本阶段 = 调研后交叉验证：对 02 的每个关键调研字段，逐字段拿去问各种网页 LLM + 权威数据，检查矛盾与冲突。
7. Commander 只派发 subagent，不直接去问；每张 builder 卡内嵌该字段的当前内容（concept/attribute/disposition/evidence/rationale）作为参数。
8. 网页 LLM 清单与具体做法见 loop/1-loop/02.5-交叉验证.md（arena.ai/agent、bigmodel glm-5.2、aistudio、perplexity、poe、chatgpt、claude、gemini、grok、copilot 等）。

10. 比较不同 LLM / 来源答案，更新字段 confidence / disposition / evidence_refs / rationale，并产出交叉验证摘要。
