# 动机社会重构（v2：谁在推动未来）

对已有著作《社会动力学与公理化体系》（GitHub: `dd2003-460/from-motivation-to-society`）的结构性重构。

**书名已改**：《谁在推动未来——从「发生了什么」到「谁在起作用」》

**核心转向**：原书是**回溯**结构（地理 → 结构 → 四领域），问「为什么是这个结果」。
新书是**前向**结构，问「**这个结果里，各因素各占多少**」。

后者才能做**反事实推演**（「如果当初没有 X，今天会怎样」），而反事实推演是预测的最小单元。

**一句话立论**：**能预测 ⟺ 有因果。这是同一个问题的两面。**
所以因果推断不需要单独引入 —— 它是「想预测未来」这个动作的内在要求。

---

## v2 相对 v1 的变化

**v1 的 Part II「演化状态空间：物质、人/相互作用」整部删除，不做替代。**

作者的判断：「太不自然了」。读者不会想「未来由什么构成」——
那是哲学家的动作，不是读者的动作。读者会问的是「我怎么知道未来会怎样」。

那层是我（AI）为了「结构严密」加上去的。**严密不等于好**：
每一步都有定义、有推导，但读者不关心你怎么定义未来，读者关心你能不能告诉他明天会发生什么。

**同时补上一个更自然的位置**：因果推断从「预测未来」内部直接长出来，
法律从「四个通道之一」升格为「这套方法最早的成熟应用」（法庭必须给出确定的数字）。

### 新结构

| | 标题 | 核心问题 |
|---|---|---|
| **导论** | 为什么算得最准的人，预测得最离谱 | 用 2008 金融危机的风险模型开场 |
| **I** | 驱动未来的引擎：动机与目标 | 要预测未来，不能只看表面数据，得看人想要什么 |
| **II** | 谁是真正的推手：预测与因果 | 知道动机凭什么就能预测？答：因果。区分相关性和原因 |
| **III** | 法庭上的时光机：多因分账 | 一堆原因搅在一起怎么算？法律界早就跑通了 |
| **IV** | 社会的四大齿轮 | 观念、经济、权力、法律在系统里怎么咬合 |
| **V** | 回到循环 | 预测出的未来如何塑造新的预测条件 |

### 面向普通读者的三条硬规则

1. **Part I 和 Part II 零公式。** 公式从 Part III 开始，且前面必须有真实案例。
2. **每个术语全书只准「正名」一次**（首次出现时括号标注），之后一律用日常说法。
3. **术语包装**：条件概率定贡献 →「**无你检验**」/「平行宇宙对比法」；
   因果推断 →「**寻找真正的幕后推手**」；模因 →「**观念的病毒**」。
   **「贡献分解」不许当小节标题**，用「分锅」「算账」「各占多少」。
