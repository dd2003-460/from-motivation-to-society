# 重构架构设计：动机-目标-预测未来

> 本文件是重构的**总纲**。从大到小：Part → 章 → 小节。
> 每层只回答三个问题：**这一层要解决什么问题** / **它从上一层的哪个问题长出来** / **它往下一层抛出什么问题**。
> 核心判据：**好人在好奇心驱动下的追问链**。每一步都必须能接上一句「但是，为什么……」。
> 风格依据：`motivation_society/补充材料/part3_AI执行指导.md`（314 行）+ `motivation_society/part1_core_logic/introduction.tex` 实样。

## 0. 重构的核心转向

### 0.1 原书的问题

原书结构是**「地理 → 结构 → 经济/文化/政治/法律」**，是一个**回溯**结构：
从结果出发，问「为什么会这样」。它的顶层驱动是**解释历史**。

这个结构有一个致命弱点（作者自己在 review_report.md 里已经点出）：
- 逻辑链在 V.2→V.3 处断裂（正交化是空间的，条件概率是因果的，两者不同构）
- 四章并列而非嵌套（part3_AI执行指导.md 错误 1 明确指出这是「四个独立科目的教科书组合」）
- **没有预测能力**。它是一本解释学，不是预测学。

### 0.2 重构后的结构

新结构是**「动机 → 目标 → 预测未来 → 条件概率定贡献 → 分解为通道」**，是一个**前向**结构：

```
动机（为什么会有这个行为）
  ↓ 加入「目标」概念
目标（行为指向哪个状态）
  ↓ 承认目标 ≠ 结果
预测未来（给定动机+目标+结构，未来怎么走）
  ↓ 承认未来不可唯一确定
条件概率定贡献（P(结果|有行为A) − P(结果|无行为A) = A 的贡献）
  ↓ 贡献要能分解
分解为通道（人模因 / 经济活动 / 政治权力 / 法律）
```

**关键转向**：原书问「为什么是这个结果」，新书问「**这个结果里，各因素各占多少**」。
前者是历史学的，后者是**预测学的**——因为只有能定贡献，才能做反事实推演
（「如果当初没有 A，今天会怎样」），而反事实推演是预测的最小单元。

### 0.3 一句话立论（检验标准）

> **如果一个陌生人读完这本书，他能用书里的公式，
> 对一个他没见过的社会事件给出概率判断，并说出「这个判断依赖于哪几个因素」。
> 那么这本书就成功了。**

这一句取代 part3_AI执行指导.md 里的旧检验标准（那 5 问只检验「统一视角」是否说清，
不检验「预测能力」是否建立）。**旧标准不够用，必须换。**

## 1. 全书五部结构（Part 级）

| Part | 标题 | 解决的核心问题 | 从哪长出来 | 往哪抛 |
|---|---|---|---|---|
| **I** | 动机与目标：从行为反推到意向 | 为什么任何解释都必须先问「动机」 | 原书 part1 ch1（存在）+ ch3（语言）合并提炼 | 动机不决定结果，因为有目标落差 → 需要「目标」 |
| **II** | 演化状态空间：物质、人、相互作用 | 要预测未来，先要规定「未来是什么」 | 目标已明确，但「未来」由什么构成？ | 有了状态还需转移规则 → 需要「相互作用」 |
| **III** | 条件概率与贡献分解 | 未来不可唯一确定时，如何定量说话 | 状态 + 相互作用 = 随机演化过程 | 条件概率怎么算贡献 → 需要分解工具 |
| **IV** | 四个通道：模因、经济、政治、法律 | 抽象的「贡献」分解成具体通道 | 有了分解原则 | 四通道不是并列，是嵌套 → 需要统一视角 |
| **V** | 预测与循环：从贡献表到未来走向 | 怎么把分解结果拼回一条时间线 | 四通道分解完成 | 回到 Part I 的动机，形成循环 |

### 1.1 依赖图（DAG）

```
P1 动机与目标
 │
 ├─→ P2 演化状态空间 ──┐
 │                     │
 └─→ P3 条件概率 ──────┼──→ P4 四通道分解 ──→ P5 预测与循环
                       │
        （P3 依赖 P2：条件概率必须定义在状态空间上）
```

- **P2 → P3 是硬依赖**：条件概率是「状态转移的条件概率」，
  不先定义状态（物质/人/相互作用），概率无从定义。
  → 这条边是原书断裂点的修复。
- **P4 → P5 是软依赖**：分解只回答「谁贡献多少」，
  「怎么拼成一条时间线」需要额外的动力学假设。
- **P5 → P1 闭环**：预测出的未来会塑造下一轮的动机与目标。
  → 循环，不是直线。

## PART I 动机与目标（P1）

**本部分要回答**：任何社会解释的最小起点是什么？为什么光有「动机」还不够？

### P1 ch1 动机：解释的最小起点

**开篇问题**：我们说「他这么做是因为…」，这句话里隐藏了什么假设？

| 小节 | 内容 | 追问链（好奇心驱动） |
|---|---|---|
| §1.1 一个最小的解释单元 | 任何解释都需要三件套：主体、动机、环境。原书把这个三件套藏在每一章开头。 | 为什么解释需要一个最小单元？→ 因为不能解释一切 |
| §1.2 动机为什么先于结构 | 追问：为什么不能先讲结构？→ 因为结构是「为了什么」才被选择的。举一个无目标的结构（地震后的墙壁残骸）对照。 | 结构的目的是什么？→ 回应动机 |
| §1.3 动机不决定结果 | **本Part的核心漏洞**。同样的动机在不同环境下产生不同结果。→ 引入「目标 ≠ 结果」 | 那动机之后是什么？→ 目标 |
| §1.4 逻辑衔接 | 目标必须先被规定，才能谈落差 | 抛给 ch2 |

**读完后读者应该能自己问出**：「那目标和结果之间的落差，用什么衡量？」

### P1 ch2 目标：把意向写成可比较的量

**开篇问题**：我们说一个人「想要 X」，X 是什么形状的东西？

| 小节 | 内容 | 追问链 |
|---|---|---|
| §2.1 目标不是名词，是排序 | 「想赚钱」不是一个目标，是一个目标集合。追问：能排序吗？ | 为什么排序？→ 因为要比较 |
| §2.2 可通约性难题 | 金钱 vs 自由 vs 生命，能换算吗？**本书明确回答：不能完全通约，且这正是政治与道德存在的理由**。 | 换算不了怎么办？→ 需要不可通约的多目标 |
| §2.3 目标函数的形式化 | 多目标效用函数：$U(x) = \sum_i w_i u_i(x_i)$。诚实说明 $w_i$ 不可观测 | 权重看不见怎么办？→ 只能从行为反推 |
| §2.4 目标函数如何反推 | 从「做了什么」反推「想要什么」（显示性偏好 / revealed preference）。诚实说明：反推有唯一性问题 | 反推不唯一怎么办？→ 转成概率 |
| §2.5 逻辑衔接 | 目标函数不可观测，只有一个可算的东西：行为发生的概率 | 抛给 P2 |

**读完后读者应该能自己问出**：「目标函数是固定的，那人和环境互动时，环境会改变目标吗？」

## PART II 演化状态空间（P2）

**本部分要回答**：要预测未来，必须先规定「未来由什么构成」。这是原书缺失的本体论。

### P2 ch3 状态三元组：物质、人、相互作用

**开篇问题**：「未来」这个词，说的是什么在变？

| 小节 | 内容 | 追问链 |
|---|---|---|
| §3.1 只写「物质」够不够 | 先复现原书 part2 的物质决定论，问：地理能解释制度吗？→ 能，但它解释不了**同一地理下不同制度** | 差异从哪来？→ 不在物质层 |
| §3.2 加入「人」 | 人不是物质，是**有目标的物质**。人的加入带来的是**偏好差异** | 偏好差异从哪来？→ 还没解决 |
| §3.3 加入「相互作用」 | 人之间、人与物质之间。人与人互动的产物叫**结构** | 结构和目标谁先？→ 一起决定 |
| §3.4 三元组的闭包性 | 追问：还需要第四个元素吗？→ 用一个封闭性论证说明三元组已足够（任何「X 决定论」都可归约为三元组中某项的权重问题） | 真的够了吗？→ 够，但要承认权重是可变的 |
| §3.5 逻辑衔接 | 有了状态，还要有「怎么变」 | 抛给 ch4 |

**读完后读者应该能自己问出**：「既然三元组已经齐了，那『变化』到底是什么？」

### P2 ch4 人存：唯一不可协商的约束

**开篇问题**：所有目标里，有没有一个是不能放弃的？

| 小节 | 内容 | 追问链 |
|---|---|---|
| §4.1 人存作为边界条件 | 追问：为了任何目标，你能接受全灭吗？→ 不能。所以**「人存」是所有目标函数的公共约束域** | 谁来执行这个约束？→ 不是道德，是结构 |
| §4.2 人存如何进入数学 | 目标函数定义域限制在「可持续集合」上：$U$ 只在 $\mathcal{S}_{\text{survive}}$ 上评估 | 边界外是什么？→ 状态变为「不可行」 |
| §4.3 从人存到生存策略 | 追问：在可持续集合内，物质约束下人怎么选？→ **这里原书 part2 ch2 的内容被重新接入，且有了正确的位置** | 为什么是这几条策略？→ 由物质约束推出 |
| §4.4 逻辑衔接 | 人存给出边界，但没给出方向 | 抛给 ch5 |

**读完后读者应该能自己问出**：「有了边界，可我还是不知道具体会走到哪一步。」

### P2 ch5 演化：相互作用如何改变状态

**开篇问题**：状态齐了、边界有了，**它怎么动**？

| 小节 | 内容 | 追问链 |
|---|---|---|
| §5.1 相互作用是唯一的引擎 | 追问：如果物质不动、人不动，状态会变吗？→ 不会。**变化只来自相互作用** | 相互作用需要消耗什么吗？→ 这是分叉点 |
| §5.2 有压扩增 vs 无压扩增 | **原书 part3_AI执行指导.md 里的核心分叉，被提升到 Part II**。有压（消耗稀缺资源，零和，收敛）／无压（传播不消耗原体，非零和，发散） | 为什么会分叉？→ 因为复制与转移的数学性质不同 |
| §5.3 互动强度决定演化速度 | 耦合强度 $\kappa$ 决定状态变化速率。$\kappa$ 太低 = 冻结，太高 = 混沌，中间才是「有历史」的区域 | 太高为什么会混沌？→ 因为预测失效 |
| §5.4 可预测窗口 | 诚实论证：$\kappa$ 中间窗口给出**有意义的预测**，两端都不给 | 这就是本书预测能力的边界 |
| §5.5 逻辑衔接 | 演化是随机的，但随机不等于不可分析 | 抛给 P3 |

**读完后读者应该能自己问出**：「随机演化，那『预测』到底在预测什么？」

## PART III 条件概率与贡献分解（P3）

**本部分要回答**：未来不唯一确定时，如何定量说话？这是原书最断裂的地方，这里是修复点。

### P3 ch6 预测的数学形式：从结果反推条件

**开篇问题**：「预测未来」在数学上到底是什么意思？

| 小节 | 内容 | 追问链 |
|---|---|---|
| §6.1 预测 = 条件概率，不是预言 | $P(\text{未来} \mid \text{现在})$。诚实说明：这不是「预知」，是「概率断言」 | 为什么不是预言？→ 因为未来依赖未观测初值 |
| §6.2 因果方向的选择 | 追问：$P(\text{结果}\mid\text{原因})$ 还是 $P(\text{原因}\mid\text{结果})$？→ **本书选前者**。原书附录 V.3 用了两个方向的混合，这正是断裂点 | 选前者的代价？→ 需要因果假设，不能纯从数据得 |
| §6.3 链条的乘积分解 | 沿因果链 $C_1 \to C_2 \to \cdots \to C_n \to R$，$P(R\mid C_0) = \prod_k P(C_k \mid C_{k-1})$。**每一步都是一个可测量的接口** | 为什么要分解成乘积？→ 因为要归因 |
| §6.4 冗余与稳健性 | 追问：如果某个 $P_k$ 很小，整条链会怎样？→ 短板效应。**这就是「历史关键杠杆点」的形式定义** | 短板怎么补？→ 冗余 |
| §6.5 逻辑衔接 | 我们能算概率了，但多个原因同时作用呢？ | 抛给 ch7 |

**读完后读者应该能自己问出**：「如果 A 和 B 都有份，各占多少？」

### P3 ch7 贡献分解：条件概率差

**开篇问题**：A 和 B 共同导致了 D，谁的贡献更大？——**这就是本 Part 的核心，也是原书 part3 ch4 那个「不够精确」问题的正式答案**。

| 小节 | 内容 | 追问链 |
|---|---|---|
| §7.1 从「有/无」到定量 | $C_A = P(D \mid A) - P(D \mid \neg A)$。先讲清这个式子在**做什么**：反事实对比 | 为什么这个差值有意义？→ 因为它是可干预的量 |
| §7.2 可干预性 = 因果的定义 | $C_A$ 存在 ⟺ A 对 D 有因果作用。这是本书对「因果」的操作性定义 | 观察性数据能算吗？→ 只能估，不能保证 |
| §7.3 多因一果的分配 | $A$、$B$ 同时作用，且有交互项。诚实处理：$C_A + C_B$ 不等于总效应，交互项必须显式 | 交互项归谁？→ 给出「按 Shapley 值或按边际贡献排序」两种方案，并说明选择理由 |
| §7.4 归一化与可读性 | $C_A / \sum C$ → 贡献份额。强调这是**可解释的**，但代价是丢掉绝对量级 | 丢了量级会怎样？→ 给出警示 |
| §7.5 逻辑衔接 | 我们有了分解原则 | 抛给 P4 填入具体通道 |

**读完后读者应该能自己问出**：「这些『通道』具体是什么？」

## PART IV 四个通道（P4）

**本部分要回答**：把贡献分解成具体的、可指认的通道。**关键：不是并列，是嵌套。**

> ⚠️ 原书最大错误就在这里（part3_AI执行指导.md 错误 1 与错误 3）。
> 旧写法是「四个独立教科书」。新写法必须是**每章是上一章的「加入一个约束」**。

### P4 ch8 通道生成器：有压 / 无压

**开篇问题**：所有社会行为，按「复制还是转移」分只有两类。

| 小节 | 内容 | 追问链 |
|---|---|---|
| §8.1 传播的两种数学形态 | 复制 $A \to A + B$（不消耗原体）vs 转移 $A \to B$（原体消失） | 为什么会分出两类？→ 因为守恒性不同 |
| §8.2 守恒性作为分类判据 | **本书第一个真正的分类原则**。守恒 → 总量约束 → 零和；不守恒 → 可以无限复制 | 守恒性怎么测？→ 找总量不变量 |
| §8.3 四通道的生成树 | 从「传播」出发，依次加入约束，每加一个分出一条新通道 → 后面四章 | 每条通道的贡献怎么算？→ 用 ch7 的式子 |
| §8.4 逻辑衔接 | 分类树建好了 | 抛给 ch9 模因 |

### P4 ch9 通道一：模因（无压扩增）

**开篇问题**：什么信息会自己传播？

| 小节 | 内容 | 追问链 |
|---|---|---|
| §9.1 模因的定义与判据 | 信息片段、复制不消耗原体、上限是接收方注意力与认知带宽 | 为什么上限在接收方？→ 因为原体不被消耗 |
| §9.2 传播强度决定一切 | 情绪激活度 > 方向正确性。**沿用原书这一条** | 为什么强度优先？→ 因为复制只需被接收 |
| §9.3 语言作为压缩层 | 原书 part1 ch3 的位置：从「核心逻辑」降到「模因的最高频压缩层」 | 为什么语言在模因之下？→ 因为它是一套被优化的压缩协议 |
| §9.4 模因的贡献分解 | $C_{\text{模因}} = P(D\mid \text{模因传播}) - P(D \mid \neg)$ | 模因贡献多大？→ 依对象而定，不能一概而论 |
| §9.5 逻辑衔接 | 模因传播不消耗资源。但如果传播**要花钱**呢？ | 抛给 ch10 |

## 3. 章节模板（每个小节都按这个结构写）

沿用原书 `chapter_edit_template.md` + `part3_AI执行指导.md` 的执行规则。

```latex
\section{小节标题}
  % ① 阅读钩子：用「你有没有想过……」把读者拽进来
  \begin{readingnote}
  你有没有想过，<一个日常到不像哲学的问题>？\\
  这背后是不是有\ \textbf{<读者能猜到但没想清楚的那一层>}？
  \end{readingnote}

  % ② 直觉先行：不带公式，先让读者有一个能抓住的图像
  （正文。类比。必须有一个具体例子，不能只有抽象陈述。）

  % ③ 反例检验：主动说出反对意见并处理
  \begin{questionbox}
  \textit{现在你可能想反驳：<读者最可能的那句话>}\\
  \textbf{<针对反驳的直接回答>}
  \end{questionbox}

  % ④ 数学形式化（可跳过）
  \begin{mathbox}{<标题>}
  （形式化。若本节无公式则省略此块，不要为形式而形式。）
  \end{mathbox}

  % ⑤ 读者可能还会问
  \begin{reader_anticipation}
  \item <问题>？ → <一句话回答，且指向本书后面的章节>
  \end{reader_anticipation}

  % ⑥ 逻辑衔接：本节末尾必须显式说明下一节为什么存在
  \paragraph*{逻辑衔接}
  我们已经<本节完成的>。但<立刻浮出的新问题>。\\
  下一节「<下一节标题>」将<解决它的方式>。
```

### 3.1 五条硬性写作规则（从原书风格提炼，不可违背）

1. **每章开头必须是上一章遗留的问题**，不能说「本章讨论 X」。
2. **每个新概念必须通过「加入一个约束」导出**，不得凭空引入。
   句式模板：「如果 A 不需要 X，那它的性质是 P。但现在加入约束 X——这一步改变了所有性质，这就是 B 从 A 中分离出来的时刻。」
3. **每小节末尾必须有 `\paragraph*{逻辑衔接}`**，显式写「下一节将……」。
4. **每章必须有一个 `logicmap`（TikZ）和一个 `motivation`（引用 + 一句话核心动机）。**
5. **每章至少一个 `\begin{reader_anticipation}`**，把读者可能的追问引向本书其他章节。

### 3.2 语言规范

- 术语格式：**中文（English）**，例如：信息级联（information cascade）
- 类比必须给具体例子，不能只有「这就像……」
- 禁止空转的强调句（AI 味）
- 诚实标注不确定处：`\lowfreq{本节结论是猜想，不是定理。}`
- 数学附录与正文的接口用 `\mathlink{label}{文字}`

## 5. 验收标准（替换原书旧检验标准）

原书旧标准只验「统一视角是否说清」。新标准必须验「预测能力是否建立」。

### 5.1 逐章五问（每章交付前自测）

1. **本章开头的「但是，为什么……」是真问题还是假问题？** 假问题 = 过渡段没写好，重写。
2. **读本章前段提出的每个问题，后文是否真的回答了？** 列出「本章未回答的问题」清单，若非空则本章不完整。
3. **有没有任何一个概念是凭空引入的？** 有则必须补「加入约束」推导段。
4. **本章是否给出了至少一个可算的量？** 若全是定性描述，本章不合格。
5. **读者能否自己问出下一章的入口问题？** 不能则逻辑衔接失败。

### 5.2 全书四问（交付前自测）

1. **给一个没读过本书的人，指一个他熟悉的社会事件，问：这本书能给出什么？** 若答案只是「统一视角」，不合格。必须是「某个因素贡献多大」的概率判断。
2. **本书能不能做反事实推演？** 「如果当初没有某制度，今天会怎样」——这必须能用 §13 的方法回答。做不到则预测能力不成立。
3. **有没有一处是并列而非嵌套？** 有则退回重写该章开头。
4. **失败模式清单是否完整且诚实？** 只有 3 条以内说明没认真想失败。

### 5.3 编译验证

- `main2.tex` 编译零错误
- 所有 `\mathlink` 和 `\hyperref` 标签有对应 `\label`
- 所有 TikZ `logicmap` 节点不重叠
- **原书 `main.tex` 与所有原章节文件字节级未改动**（用 `git diff --stat` 验证）
