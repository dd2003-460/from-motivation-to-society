## 2. 断裂点的精确定位

### 2.1 D1 的机制

原书的信息论路线与因果路线是**两套互不兼容的数学**：

```
信息论路线（part1 ch3 + 附录 V.2）：
  高频 → 压缩 → 变长编码 → Shannon 熵 → Gram-Schmidt 正交化
  空间结构：把信号投影到正交基上，去掉冗余

因果路线（part3 ch4 + 附录 V.3）：
  条件概率 P(结果|原因) → 链式分解 → 贡献度
  因果结构：沿时间链求条件概率的乘积
```

两者都是「分解」，但：
- 正交化是**空间的**（同一时刻的信号向量）
- 条件概率是**时间的**（跨时刻的状态转移）

原书没有说明这两者为何能放在同一本书里，也没有公理把它们接起来。**这不是排版问题，是数学结构问题。**

### 2.2 新结构的修复方式

```
Part II 先定义状态空间 S = (物质, 人, 相互作用)
       ↓
Part III 只在 S 上定义条件概率：P(S_{t+1} | S_t)
       ↓
信息论降级为「模因通道的压缩工具」（P4 ch9 §9.3）
因果论成为唯一的公理基础
```

这样：
- 条件概率有了定义域（状态空间），不再是悬空的
- 信息论不再是公理，是一个具体通道的属性
- 正交化和条件概率不再并列出现，冲突消失

**代价**：新结构必须先讲完 Part II 才能讲 Part III，比原书多一层铺垫。但换来的是数学上自洽。

## 4. 必须避免重复的错误

派活时已写进 prompt，此处留档：

| 错误 | 表现 | 检测方法 |
|---|---|---|
| E1 并列而非嵌套 | 某章可以独立阅读 | 问：删掉上一章，这章还成立吗？成立 ⇒ 并列 ⇒ 重写开头 |
| E2 空话填充 | 「值得注意的是」「显而易见」 | 搜这些词；命中即重写 |
| E3 强行形式化 | 为有公式而写 mathbox | 问：这个公式改变了任何结论吗？没有 ⇒ 删掉 |
| E4 假因果 | 「因为 A 所以 B」但 A 不可干预 | 问：这个 A 能被人为开关吗？不能 ⇒ 不是因果 |
| E5 藏判断题 | Agent 遇到不确定但不报告 | prompt 里明确要求报告；报告了要奖励 |
