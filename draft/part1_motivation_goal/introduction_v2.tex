	\begin{motivation}
		2008 年秋天，华尔街拥有全世界最多的数据、最贵的博士、最复杂的模型。然后它预测错了一切。\\
		\textbf{核心动机}：这本书不教你预测股价，它问一个更尖的问题——为什么一群最会算的人，预测得最离谱？答案不在数学，在「因果」。本书要给的，是一套从法庭到科学界都在用的、拆解「谁真正推动了结果」的工具。
	\end{motivation}

	\section{钩子：为什么算得最准的人，预测得最离谱}

	\begin{readingnote}
		你有没有想过：那些在 2007 年还能用复杂模型给次贷评级为「安全」的机构，手里握着几十年的房价数据、成千上万的博士、每秒万亿次的算力——\\
		他们不是算错了，他们是「算对了一件事，却预测错了一切」。这中间的裂缝，到底是什么？
	\end{readingnote}

	2008 年金融危机里最反直觉的一幕是：亏损最惨的，往往不是信息最少的人，而是信息最多的人。大银行的量化部门能精确算出一份衍生品的理论价格，却算不出「如果房价跌 10\%，整条链会不会断」。他们的模型在「过去发生过什么」上极其精确，在「接下来会发生什么」上极其盲目。

	这不是孤例。苏联崩溃前，几乎每一家主流智库都预测它会长期存在；无数专家对一次次社会转折给出了事后看来荒唐的判断。共同的失败模式不是「数据不够」，而是把\textbf{描述过去}和\textbf{预测未来}当成了同一件事。它们不是同一件事——这是整本书要展开的论点。

	\paragraph*{逻辑衔接}
	他们到底缺了什么？不是更多的统计，是一种更古老的能力：看懂「局中人的动机」，以及区分「两件事相关」和「一件事导致了另一件」。下一节做诊断。

	\section{诊断：他们懂统计，却不懂因果}

	\begin{readingnote}
		你有没有遇过这种人：能背出一堆相关数字（「冰淇淋销量和溺水人数正相关」），却认真建议「夏天少卖冰淇淋来防淹死」？\\
		相关和因果之间的那道缝，就是大多数失败预测掉进去的地方。
	\end{readingnote}

	那些最会算的人，模型里缺的不是数学，是\textbf{因果}。一个只记录「过去 A 和 B 同时出现」的模型，永远分不清「A 导致 B」和「是 C 同时导致了 A 和 B」。它能在平稳时期把历史拟合得天花乱坠，一旦环境变了就全盘崩溃——因为拟合历史不需要理解机制，预测未来需要。

	而比因果更底层的，是\textbf{动机}。房价为什么会涨？因为有人在买、有人在做空、有人在被 KPI 逼着包装风险。如果只看价格曲线，你看到的是结果；如果看局中人的动机，你才看到驱动。本书的第一站（Part I）就是：要预测未来，不能只盯表面数据，得先弄懂「人到底想要什么」。

	这里要先交个底：能预测，和能因果，其实是一回事。你能预测改变 A 之后的结果，说明你知道 A 是不是原因；你知道 A 是不是原因，你就能预测改变 A 之后的结果。本书把目标明确限定为——\textbf{预测「社会在不同选择下会走向哪里」}，而不是预测趋势。前者需要因果，后者只需要拟合。

	\paragraph*{逻辑衔接}
	诊断完了：缺的是因果，而因果的根基是动机。那这套工具具体长什么样、怎么从「想预测」里长出来？下一节给出全书的承诺与地图。

	\section{承诺：一套从法庭到科学界都在用的工具}

	\begin{readingnote}
		同样要「分锅」的场景，其实天天在发生：法庭上法官要判「这起事故里，各方各占几成责任」；流行病学要判「这种病和那种暴露各有多大关系」；你复盘一次项目失败，也要判「哪个决策是主因」。\\
		这些看似无关的领域，用的是同一套底层动作。
	\end{readingnote}

	这本书不给水晶球。它给的是一套拆解工具：当一堆因素搅在一起导致了某个结果，怎么把「各占多少」定成一个可比的量。最妙的是，这套工具不是书斋里的发明——法官们被迫天天使用它，而且不许给模糊答案，必须说出「70\% 是他的责任」。本书要做的事，是把这套已经被真实世界验证过几千年的方法，从「判案」推广到「预测」。

	所以全书的目标始终是：让你对一件\textbf{还没发生}的事，也能给出有依据的判断，并说清「这个判断依赖哪几个因素」。这正是预测的最小单元——反事实推演：如果当初没有 X，今天会怎样。

	\paragraph*{逻辑衔接}
	工具是什么、为谁而写，先说清。下一节给全书地图，让你随时知道自己在哪。

	\section{面向读者群体}

	\begin{readingnote}
		你有没有想过，为什么同一本书，有人嫌太数学看不懂，有人嫌不够数学没深度？\\
		这反映的其实是\textbf{读者背景的多样}。一本讲「预测的社会科学」的书，怎么让不同背景的人都有收获？
	\end{readingnote}

	本书在两个极端之间寻找平衡：数理严谨性与社科可读性。处理方式是——正文用自然语言推进直觉，关键概念配一个「数学建模」盒子放形式化，\textbf{可跳过}，但跳过之后你要接受「知其然」的折扣。

	因此本书的目标读者包括：
	\begin{itemize}
		\item 希望理解社会系统如何被\textbf{前向推导}的自然科学背景者
		\item 愿意接受概率工具、但不希望被公式淹没的社会科学研究者
		\item 对「社会能不能预测」这个问题本身感兴趣的普通读者
	\end{itemize}

	第三类读者请注意：本书的「预测」是\textbf{概率断言}，不是\textbf{预言}。说「降水概率 70\%」的气象学家，和说「明天必然下雨」的巫师，做的是两种完全不同的事。

	\paragraph*{逻辑衔接}
	为谁而写、以及「预测」的边界说清了。接下来是结构问题：这条前向的链长什么样？下一节给全书地图。

		差别往往不在内容，而在\textbf{结构}——章节之间是并列摆放，还是彼此咬合？

	每一站都长在上一站遗留的问题上：
	\begin{itemize}
		\item \textbf{动机与目标}（Part I）：要预测未来，先得看懂人想要什么。动机为什么是预测的必要输入，而非解释的终点？
		\item \textbf{预测与因果}（Part II）：既然看懂了动机，凭什么能预测？答：因为能预测就等价于有因果。区分「相关」与「原因」。
		\item \textbf{法庭上的时光机}（Part III）：一堆原因搅在一起怎么算？答：法律界几千年前就逼出了这套方法——必须给一个确定的数字。这是方法的证明。
		\item \textbf{社会的四大齿轮}（Part IV）：社会上的因果具体长什么样？套用工具拆成四个通道——模因、经济、政治、法律。\textbf{不是并列，是嵌套}。
		\item \textbf{回到循环}（Part V）：预测出的未来，会反过来塑造下一轮的动机。循环闭合。
	\end{itemize}

	写作上有两条铁律贯穿全书：其一，\textbf{每章开头都是上一章遗留的问题}；其二，\textbf{每个新概念都通过「加入一个约束」导出}——如果 A 不需要 X，性质是 P；加入约束 X，所有性质随之改变，这就是 B 从 A 中分离出来的时刻。

	\paragraph*{逻辑衔接}
	结构图有了。但一条环环相扣的链，会不会把读者锁死在单一读法里？下一节给出阅读策略。

	\section{如何阅读本书}

	\begin{readingnote}
		你有没有遇到过：有些书\textbf{结构清晰}却枯燥，有些书\textbf{生动}却杂乱？\\
		如果一本书想既保持逻辑统一、又允许灵活阅读——这可能吗？
	\end{readingnote}

	\subsection{线性阅读路径}
	如果这是你第一次接触这类前向推导的思考，建议按目录顺序读。这条链的依赖是真实的：不先有动机与目标（Part I），预测与因果（Part II）就悬空；不先有因果工具，法庭（Part III）和方法应用就接不上。

	\subsection{跳跃阅读路径}
	如果你已有相关背景，可按问题跳读。每一章开头的「逻辑地图」标明该章位置与前后依赖；每一节末尾的「逻辑衔接」显式写出「下一节将解决什么」——它们合起来是一张可脱离正文使用的全书地图。想直接看「各占多少」的读者，可以从 Part III 进入，缺什么再回 Part II 补。

	\subsection{正向建构与反向学习}
	从基本原理向下读（正向建构）和从具体问题向上回溯（反向学习），是对\textbf{同一结构的两种线性遍历方式}，并不冲突。本书没有原书那种「状态空间 $\rightarrow$ 条件概率」的硬依赖边，所以反向阅读时不必担心踩空——你缺的概念，总能在它出现的那一章找到。

	\paragraph*{逻辑衔接}
	读法交代完毕。还剩最后一件事：把「这本书成功了」说清楚——否则「预测」会滑向它最俗的意义。下一节给全书唯一的检验标准。

	\section{检验标准：一句话立论}

	\begin{readingnote}
		你有没有想过，为什么听了一场「大势分析」之后热血沸腾，三个月后发现什么也没预测对？\\
		因为\textbf{没有可检验断言}的预测，只是情绪按摩。一本书的预测力，必须有验收标准。
	\end{readingnote}

	本书的验收标准只有一句话：

	\begin{quote}
		\textbf{如果一个陌生人读完这本书，他能用书里的工具，对一个他没见过的社会事件给出概率判断，并说出「这个判断依赖于哪几个因素」——那么这本书就成功了。}
	\end{quote}

	相应地，「我们能说什么 / 我们不能说什么」必须分开写。本书能给的：对一个事件，一组因素的贡献排序与概率断言；对一个「如果当初没有 X」的问题，一条可辩护的反事实推演。本书不能给的：明天的股价、下一位候选人、战争的具体日期。

	\paragraph*{逻辑衔接}
	标准立好了。接下来正式进入正文——从最日常的一句话开始：「他这么做，是因为……」。第1章「动机：解释的最小起点」将拆开这句话，看里面藏着什么假设。

	\section{章节预告}

	\begin{itemize}
		\item \hyperref[ch:motivation]{第1章 动机：解释的最小起点}——「他这么做是因为……」这句话里隐藏了什么假设？动机为什么是预测的必要输入。
		\item \hyperref[ch:goal]{第2章 目标：把意向写成可比较的量}——「想要 X」里的 X 是什么形状？排序、不可通约性、效用函数，最后退到概率。
		\item \hyperref[ch:prediction]{第3章 预测与因果}——「能预测」和「有因果」为什么是同一件事？相关不等于原因。
		\item \hyperref[ch:contribution]{第4章 贡献分解：无你检验}——A 和 B 共同导致 D，各占多少？把「各占多少」定成一个可比的量。
		\item \hyperref[ch:law-method]{第5章 法庭上的时光机}——法律界几千年前就逼出了这套方法；它是因果贡献分解最早的成熟应用。
		\item \hyperref[ch:channels]{第6章 通道生成器}——所有社会行为，按「复制还是转移」分只有两类。
		\item \hyperref[ch:meme]{第7章 模因}、\hyperref[ch:economy]{第8章 经济}、\hyperref[ch:politics]{第9章 政治}、\hyperref[ch:law]{第10章 法律}——四个齿轮，逐层加约束。\textbf{嵌套，不是并列}。
		\item \hyperref[ch:forecast]{第11章 从贡献表到未来走向}——怎么把分解结果拼回一条时间线？
		\item \hyperref[ch:closure]{第12章 循环的闭合}——预测出的未来，会不会反过来塑造新的动机？
	\end{itemize}

	\paragraph*{逻辑衔接}
	路线图已经摊开。现在，让我们从一个最日常的动作开始——解释。当你说出「他这么做，是因为……」的那一刻，你已经站在了整本书的起点上。
