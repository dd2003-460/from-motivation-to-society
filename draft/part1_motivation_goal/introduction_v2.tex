	\begin{motivation}
		2008 年秋天，华尔街拥有全世界最多的数据、最贵的博士、最复杂的模型。然后它预测错了一切。\\
		\textbf{核心动机}：这本书不教你预测股价，它问一个更尖的问题——为什么一群最会算的人，预测得最离谱？答案不在数学，在「因果」。本书要给的，是一套从法庭到科学界都在用的、拆解「谁真正推动了结果」的工具。
	\end{motivation}

	\section{钩子：为什么算得最准的人，预测得最离谱}

	你有没有想过，2008 年亏得最惨的，往往不是那些啥都不懂的小散户，而是华尔街里数据最多、博士最多的那拨人？

	你可能会说：这不正常啊，信息多不是应该更准吗？

	没错——但问题恰恰出在"信息多"上。大银行的量化部门能精确算出一份衍生品的理论价格，却算不出"如果房价跌 10\%，整条链会不会断"。他们的模型在"过去发生过什么"上极其精确，在"接下来会发生什么"上极其盲目。

	\begin{tcolorbox}[colback=yellow!5, title=\textit{读者行为预测}]
		现在你可能想反驳："可他们模型在平稳年代明明很准啊，你不能说他们完全不会算。"\\
		\textbf{啊哈，我就猜到你会这么想。}准，是因为那段日子没出意外；一旦环境变了，它连"自己之前为什么准"都解释不了。这恰恰是最危险的一种不会算——它让你在暴风雨来之前，觉得自己已经看懂了天气。
	\end{tcolorbox}

	这不止一次。苏联崩溃前，西方情报机构年年写报告说"体制稳定，短期内无崩溃迹象"；2007 年，评级机构把一堆垃圾债贴上 AAA 的安全标签。共同的失败不是"数据少"，而是一个更隐蔽的错觉：把\textbf{描述过去}和\textbf{预测未来}当成了同一件事。

	\textbf{\Large 关键洞见}：他们算对了一件事——过去；却预测错了一切——未来。这中间的裂缝，就是整本书要填的。

	\paragraph*{逻辑衔接}
	他们到底缺了什么？不是更多的统计，而是一种更古老的能力：看懂"局中人的动机"，以及分清"两件事相关"和"一件事导致了另一件"。下一节做诊断。

	\section{诊断：他们懂统计，却不懂因果}

	你有没有遇过这种人：能背出一堆相关数字（"冰淇淋销量和溺水人数正相关"），却认真建议"夏天少卖冰淇淋来防淹死"？

	相关和因果之间的那道缝，就是大多数失败预测掉进去的地方。那些最会算的人，模型里缺的一样东西，恰恰是他们最看不上的——因果。一个只记录"过去 A 和 B 同时出现"的模型，永远分不清"A 导致 B"和"是 C 同时导致了 A 和 B"。

	\begin{tcolorbox}[colback=green!5, title=\textit{生活类比}]
		这就像一个只会背过去十年天气的人，从没学过"为什么"会下雨。明天台风来了，他照样懵——因为他记的是"哪天晴哪天下雨"，不是"下雨的机制"。描述得再精确，也预测不了下一次。
	\end{tcolorbox}

	而比因果更底层的，是\textbf{动机}。房价为什么会涨？因为有人在买、有人在做空、有人在被 KPI 逼着包装风险。如果只看价格曲线，你看到的是结果；如果看局中人的动机，你才看到驱动。本书第一站（Part I）就是：要预测未来，不能只盯表面数据，得先弄懂"人到底想要什么"。

	这里要先交个底：能预测，和能因果，其实是一回事。你能预测"改变 A 之后的结果"，说明你知道 A 是不是原因；你知道 A 是不是原因，你就能预测"改变 A 之后的结果"。本书把目标明确限定为——\textbf{预测"社会在不同选择下会走向哪里"}，而不是预测趋势。前者需要因果，后者只需要拟合。

	\begin{tcolorbox}[colback=yellow!5, title=\textit{读者行为预测}]
		你八成要杠："天气预报不也预测吗？它管什么因果？"\\
		\textbf{问得好，这正是本书要绕开的坑。}天气预报预测的是"趋势"——给定当前大气状态，推下一步。它答不了"如果我人工降雨，会不会下雨"。而本书要干的，恰恰是这种"如果当初没有 X，今天会怎样"的干预性预测。所以本书的"预测"，是带因果的那种。
	\end{tcolorbox}

	\textbf{\Large 关键洞见}：能预测 $\Leftrightarrow$ 有因果。这一条是全书枢纽，后面所有工具都挂在它上面。

	\paragraph*{逻辑衔接}
	诊断完了：缺的是因果，而因果的根基是动机。那这套工具具体长什么样、怎么从"想预测"里长出来？下一节给出全书的承诺与地图。

	\section{承诺：一套从法庭到科学界都在用的工具}

	同样要"分锅"的场景，其实天天在发生：法庭上法官要判"这起事故里，各方各占几成责任"；流行病学要判"这种病和那种暴露各有多大关系"；你复盘一次项目失败，也要判"哪个决策是主因"。这些看似无关的领域，用的是同一套底层动作。

	这本书不给水晶球。它给的是一套拆解工具：当一堆因素搅在一起导致了某个结果，怎么把"各占多少"定成一个可比的量。

	\begin{tcolorbox}[colback=green!5, title=\textit{生活类比}]
		最妙（不对，最实在）的例子就在法庭：法官不许给模糊答案，必须说出"这起事故 70\% 是他的责任，30\% 是天气"。逼着自己把"谁推了一把"算成一个数字——这件事法院天天干，干了上千年。本书要做的事，就是把这套已经被真实世界验证过的方法，从"判案"推广到"预测"。
	\end{tcolorbox}

	所以全书的目标始终是：让你对一件\textbf{还没发生}的事，也能给出有依据的判断，并说清"这个判断依赖哪几个因素"。这正是预测的最小单元——反事实推演：如果当初没有 X，今天会怎样。（示范了一下什么叫反事实推演。）

	\paragraph*{逻辑衔接}
	工具是什么、为谁而写，先说清。下一节给全书地图，让你随时知道自己在哪。

	\section{面向读者群体}

	你有没有想过，为什么同一本书，有人嫌太数学看不懂，有人嫌不够数学没深度？

	这反映的其实是\textbf{读者背景的多样}。写一本讲"预测的社会科学"的书，怎么让不同背景的人都有收获？本书在两个极端之间找平衡：数理严谨性与社科可读性。处理方式是——正文用自然语言推进直觉，关键概念配一个"数学建模"盒子放形式化，\textbf{可跳过}，但跳过之后你要接受"知其然"的折扣。

	本书的目标读者包括：
	\begin{itemize}
		\item 希望理解社会系统如何被\textbf{前向推导}的自然科学背景者
		\item 愿意接受概率工具、但不希望被公式淹没的社会科学研究者
		\item 对"社会能不能预测"这个问题本身感兴趣的普通读者
	\end{itemize}

	第三类读者请注意：本书的"预测"是\textbf{概率断言}，不是\textbf{预言}。说"降水概率 70\%"的气象学家，和说"明天必然下雨"的巫师，做的是两种完全不同的事。

	\paragraph*{逻辑衔接}
	为谁而写、以及"预测"的边界说清了。接下来是结构问题：这条前向的链长什么样？下一节给全书地图。

	每一站都长在上一站遗留的问题上，不是随便摆的：
	\begin{itemize}
		\item \textbf{动机与目标}（Part I）：要预测未来，先得看懂人想要什么。动机为什么是预测的必要输入？
		\item \textbf{预测与因果}（Part II）：看懂了动机，凭什么能预测？答：能预测就等价于有因果。
		\item \textbf{法庭上的时光机}（Part III）：一堆原因搅在一起怎么算？法律界几千年前就逼出了这套方法——必须给一个确定的数字。
		\item \textbf{社会的四大齿轮}（Part IV）：社会上的因果具体长什么样？拆成模因、经济、政治、法律四个通道，逐层加约束。
		\item \textbf{回到循环}（Part V）：预测出的未来，会反过来塑造下一轮的动机。循环闭合。
	\end{itemize}

	顺带交底一处用法：Part IV 讲模因时会借用「压缩」的直觉（好记的短、难记的长），但\textbf{本书不把信息论当公理}——只借直觉，不立公理；其严格形式化挂账于待发表的《介观统一论》。

	写作上有两条铁律贯穿全书：每章开头都是上一章遗留的问题；每个新概念都通过"加入一个约束"导出。如果你读着读着觉得"这节怎么又从问题开始的"——对，那就是故意的（狗头）。

	\paragraph*{逻辑衔接}
	结构图有了。但一条环环相扣的链，会不会把读者锁死在单一读法里？下一节给出阅读策略。

	\section{如何阅读本书}

	你有没有遇到过：有些书\textbf{结构清晰}却枯燥，有些书\textbf{生动}却杂乱？如果一本书想既保持逻辑统一、又允许灵活阅读——这可能吗？

	\subsection{线性阅读路径}
	如果这是你第一次接触这类前向推导的思考，建议按目录顺序读。这条链的依赖是真实的：不先有动机与目标（Part I），预测与因果（Part II）就悬空；不先有因果工具，法庭（Part III）和方法应用就接不上。

	\subsection{跳跃阅读路径}
	如果你已有相关背景，可按问题跳读。每一章开头的"逻辑地图"标明该章位置与前后依赖；每一节末尾的"逻辑衔接"显式写出"下一节将解决什么"。想直接看"各占多少"的读者，可以从 Part III 进入，缺什么再回 Part II 补。

	\subsection{正向建构与反向学习}
	从基本原理向下读（正向建构）和从具体问题向上回溯（反向学习），是对\textbf{同一结构的两种线性遍历方式}，并不冲突。本书没有原书那种"状态空间 $\rightarrow$ 条件概率"的硬依赖边，所以反向阅读时不必担心踩空——你缺的概念，总能在它出现的那一章找到。

	\paragraph*{逻辑衔接}
	读法交代完毕。还剩最后一件事：把"这本书成功了"说清楚——否则"预测"会滑向它最俗的意义。下一节给全书唯一的检验标准。

	\section{检验标准：一句话立论}

	你有没有想过，为什么听了一场"大势分析"之后热血沸腾，三个月后发现什么也没预测对？因为没有可检验断言的预测，只是情绪按摩。

	本书的验收标准只有一句话：

	\begin{quote}
		\textbf{如果一个陌生人读完这本书，他能用书里的工具，对一个他没见过的社会事件给出概率判断，并说出"这个判断依赖于哪几个因素"——那么这本书就成功了。}
	\end{quote}

	相应地，"我们能说什么 / 我们不能说什么"必须分开写。本书能给的：对一个事件，一组因素的贡献排序与概率断言；对一个"如果当初没有 X"的问题，一条可辩护的反事实推演。本书不能给的：明天的股价、下一位候选人、战争的具体日期。

	\paragraph*{逻辑衔接}
	标准立好了。接下来正式进入正文——从最日常的一句话开始："他这么做，是因为……"。第1章「动机：解释的最小起点」将拆开这句话，看里面藏着什么假设。

	\section{章节预告}

	\begin{itemize}
		\item \hyperref[ch:motivation]{第1章 动机：解释的最小起点}——「他这么做是因为……」这句话里隐藏了什么假设？动机为什么是预测的必要输入。
		\item \hyperref[ch:goal]{第2章 目标：把意向写成可比较的量}——「想要 X」里的 X 是什么形状？排序、不可通约性、效用函数，最后退到概率。
		\item \hyperref[ch:prediction]{第3章 预测与因果}——「能预测」和「有因果」为什么是同一件事？相关不等于原因。
		\item \hyperref[ch:contribution]{第4章 贡献分解：无你检验}——A 和 B 共同导致 D，各占多少？把"各占多少"定成一个可比的量。
		\item \hyperref[ch:law-method]{第5章 法庭上的时光机}——法律界几千年前就逼出了这套方法；它是因果贡献分解最早的成熟应用。
		\item \hyperref[ch:channels]{第6章 通道生成器}——所有社会行为，按「复制还是转移」分只有两类。
		\item \hyperref[ch:meme]{第7章 模因}、\hyperref[ch:economy]{第8章 经济}、\hyperref[ch:politics]{第9章 政治}、\hyperref[ch:law]{第10章 法律}——四个齿轮，逐层加约束。
		\item \hyperref[ch:forecast]{第11章 从贡献表到未来走向}——怎么把分解结果拼回一条时间线？
		\item \hyperref[ch:closure]{第12章 循环的闭合}——预测出的未来，会不会反过来塑造新的动机？
	\end{itemize}

	\paragraph*{逻辑衔接}
	路线图已经摊开。现在，让我们从一个最日常的动作开始——解释。当你说出「他这么做，是因为……」的那一刻，你已经站在了整本书的起点上。
