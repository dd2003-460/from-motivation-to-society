\chapter*{前言}
\addcontentsline{toc}{chapter}{前言}

\begin{motivation}
	我写这本书，只有一个目的：让尽可能多的人\textbf{了解到自己}——看懂自己此刻的处境是怎么来的，顺手也看懂别人的。共鸣有了，人才会把它转给下一个人。这本书的全部野心，就是把「转给下一个人」这件事的概率做大。\\
	\textbf{核心动机}：把「预测社会」从水晶球生意，改造成一门普通人能上手的手艺。
\end{motivation}

\section{为什么会有这一版}

你有没有想过，为什么有些书解释力很强，读完却什么也做不了？

我的上一本书《社会动力学与公理化体系》就有点这个毛病。它回答了一个大问题：地理、文化、经济、政治、法律，能不能被塞进同一条推导链？答案是能。但自审的时候，我自己承认了三个硬伤：

\begin{itemize}
	\item \textbf{数学是断的}。附录里从「空间正交化」直接跳到「因果条件概率」，两者不同构——一个是几何，一个有方向。链在那里断了。
	\item \textbf{四个领域是并列的}。文化、经济、政治、法律各写一章，像四本教科书合订。读者记不住它们是同一件事。
	\item \textbf{最要命的：它只会解释，不会预测}。只解释不预测的社会理论，像只有后视镜的汽车——看得清来路，看不清前路。
\end{itemize}

\begin{readingnote}
	你有没有想过，为什么「事后分析」头头是道的人，事前往往沉默？\\
	因为「解释已经发生的」和「预测还没发生的」，是两种能力。上一本书只训练了前一种。
\end{readingnote}

所以有了这一版。主线只有一句话：\textbf{从「想预测未来」这个动作出发}。因果工具自己会长出来，法庭早就把它跑通了，最后把它装到社会运转的齿轮上。这是前向的写法：每个新概念，都是上一个问题「但是，为什么……」的答案。

\section{这一版改了什么}

三处大改动，我在开头就挑明。

\begin{enumerate}
	\item \textbf{砍掉一整层}。旧版有一层「演化状态空间」，规定未来由物质、人、相互作用构成。写完我自己都觉得别扭——那是写给哲学家的动作。读者问的是「我怎么知道明天会发生什么」，不是「未来是什么东西做的」。砍了。
	\item \textbf{因果从「预测」里长出来}。我的论断是：能预测，就等价于有因果。天气预报能预测明天，却答不了「如果我人工降雨，会不会下雨」。后者只有因果能做到。所以本书只管一件事：预测「社会在不同选择下会走向哪里」。
	\item \textbf{法律升格为方法的证明}。旧版把法律当四个通道之一。这一版把它提前：法庭必须给出「七成责任归他」这种确定数字，这种压力逼着人类把「谁起的作用」算了几千年。Part III 看方法怎么被逼出来，Part IV 再看它在系统里怎么咬合。法律出现两次，是两个角度，不是重复。
\end{enumerate}

\begin{questionbox}
	\textit{现在你可能想反驳：「社会这么乱，怎么可能预测？这不是科学傲慢吗？」}\\
	\textbf{我同意一半。}所以我从头到尾不说「预言」，只说「概率断言」。说「降水概率七成」的气象员，和说「明天必下雨」的巫师，干的是两种活。这本书学的是前者。
\end{questionbox}

\section{怎么读这本书}

全书六段：导论先看一次预测大翻车；Part I 拆「人想要什么」；Part II 拆「凭什么能预测」；Part III 进法庭看分账；Part IV 把工具装到观念、经济、权力、法律四个齿轮上；Part V 回到循环——预测本身会改变未来。

\begin{itemize}
	\item \textbf{怕公式}？跳过所有「数学建模」盒子，读正文不受伤。公式集中在 Part III 之后和数学附录，前面都配了真实案例。
	\item \textbf{想知道结论多可靠}？盯红色强调和 \texttt{\textbackslash lowfreq} 标注——那是我写「这是猜想，不是定理」的地方。
	\item \textbf{赶时间}？每节末尾的「逻辑衔接」写了下一节解决什么，可以按需跳。
\end{itemize}

还有一句诚实话，我要放在最前面：这本书给的是\textbf{结构}，不是\textbf{预言}。它能告诉你一件事「依赖哪几个因素、各占多少」，不能告诉你「明天会发生什么」。方法会在哪里失灵，第 15 章列了一张失败清单——那是这本书可信度的一部分，不是污点。一本讲预测的书，自己先不诚实，就完了。

\begin{reader_anticipation}
	\item 书里的「预测」到底能干嘛？→ 导论就给检验标准：对一个没见过的事件，给出概率判断，并说出依赖哪几个因素。
	\item 没读过上一本会有障碍吗？→ 完全没有。这一版从第一页重新长，旧书的材料都搬进了新结构，但不需要旧书垫底。
\end{reader_anticipation}

\paragraph*{逻辑衔接}
	前言交代了「为什么重写、改了什么、怎么读」。但还有一个问题我没回答：凭什么说「算得最准的人预测得最离谱」？这不是为了耸动——2008 年秋天真的发生了。\\
	下一节进入导论，从那场危机的第一手细节讲起。

\begin{thinkbox}
\begin{enumerate}
	\item 你手边有没有一个「解释起来头头是道、事前完全没料到」的事？试着用「描述过去 $\neq$ 预测未来」拆一下：当时缺的是数据，还是别的什么？
	\item \textbf{反事实}：如果 2008 年那场危机没有发生，这本书还会从预测失败开场吗？如果没有那批「算得最准的人」集体翻车，「能预测就等价于有因果」这个论断，你还会觉得重要吗？
\end{enumerate}
\end{thinkbox}
