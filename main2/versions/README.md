# versions/ — 多人群导读与例子替换笔记（次要交付物）

总目标：**让尽可能多的人了解自己、引发共鸣、增大裂变传播的 K 因子**（见
`../../skills/motivation-society-style/SKILL.md` §十三）。

正文（`main2.tex` 那 17 个 subfile）按「希望了解结构的人」基准写，推导链最完整。
这四份笔记是从正文衍生的**导读 + 例子替换 + 密度调整**方案，不是重写全书：

| 版本 | 读者 | 文件 | 写法重心 |
|---|---|---|---|
| 学生版 | 中学生 / 大学生 | `students.md` | 考试排名、选专业焦虑；少公式，多「原来如此」 |
| 上班族版 | 职场人 / 家庭采购者 | `office-workers.md` | 菜价、房贷、晋升、短视频；直接答「跟我有什么关系」 |
| 结构内行版 | 专业读者 / 研究者 | `insiders.md` | 锋利工具与反直觉边界；不重复基础；亮失败处 |
| 结构学习者版 | 好奇的聪明外行 | `structure-learners.md` | 认知脚手架：先地图，再带走推导 |

每份笔记统一四栏：

1. **一句话定位**（这本书对 TA 是什么）；
2. **章节切入与例子替换表**（钩子例子换什么、哪些正文例子保留）；
3. **公式与密度调整**（mathbox 保留 / 跳过 / 加码）；
4. **K 因子话术**（TA 会转给谁、转的时候说什么）。

> 纪律：例子池里的素材（菜价、短视频茧房、职场晋升、王安石、丝绸之路、宗教改革、
> 房价、高考、流行病谣言）是**公共池**，四个版本各取所需，正文里都已埋好，替换笔记
> 只做「抽取 + 重排序」，不新编史实。任何新增例子必须先过「双轨 + 跨人群」检验。
