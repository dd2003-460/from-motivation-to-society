# 结构内行版导读（专业读者 / 研究者）

## 一句话定位

> 这本书不教你因果推断入门——它赌一个论断：**能预测 ⟺ 有因果**，
> 并把法律当方法的成熟应用来抄作业。你要看的是它的**边界与失败处**。

## 明示的模型缺陷（正文已标，此处集中）

1. 状态空间未经公理化（旧版断裂点修复的代价：只给操作定义）；
2. $C_A$ 估量依赖三把镊子，无统一估计量；
3. 四通道嵌套是**直觉呈现**，严格推导在《介观统一论》，本书不假装证明；
4. 反身性只作失败模式，未给形式化（预期的固定点理论是缺口）。
