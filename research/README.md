# research/ — 多人群共鸣与扩散的实证研究

> 本文件夹服务于《动机社会》总目标：**让尽可能多的人了解自己、引发共鸣、增大裂变 K 因子**。
> 这里只放**实证研究**产出（真实数据 + 综述 + 对写作的可操作结论），不放书稿正文。

---

## 一、研究目的（为什么需要这个文件夹）

书的正文与多人群版本（students / office-workers / insiders / structure-learners）要「引发共鸣、扩散出去」，不能只靠作者直觉。本文件夹用**真实大样本数据**回答：观念（meme）在人群里到底怎么传、谁传、传多快、为什么停。结论反哺写作——告诉每类人群该用哪种钩子、哪种机制。

强制依据：`../skills/motivation-society-style/SKILL.md` §十三 13.3「实证数据强制要求」、 `../main2/README.md` 约束 H。

---

## 二、研究问题（更完善的 goal）

1. **观念接受与变形**：一个小团体里，一条 meme 被接受、复述、改编的机制是什么？复述失真方向是否有规律（例如简化、极端化、情绪强化）？
2. **共鸣触发机制**：什么驱动一条内容在小群体内触发转发 / 共鸣？候选机制（需实证检验，不预设）：情绪唤醒、身份认同、信息缺口（curiosity gap）、稀缺性、社会证明（social proof）。
3. **K 因子 / 基本再生数量级**：真实世界里内容的 K 因子（或等效基本再生数 R）分布如何？哪些内容 >1（自我维持传播），哪些 ≪1？不同平台 / 体裁差异多大？
4. **人群差异**：学生 / 上班族 / 结构内行 / 结构学习者 对同一类内容的共鸣与转发行为差异，是否有大规模实证支持？
5. **跨时空共通框架**：宗教改革、丝绸之路、王安石变法 等历史扩散，与当下短视频 / 社交平台的 meme 扩散，能否用同一套量化框架（通道生成器 + K 因子）描述？历史案例的真实传播规模数据能否找到？

---

## 三、数据要求（硬约束，必须做到）

- **真实数据，三选一或并用**：
  - 公开可引用的 meme / 内容数据集（论文附带扩散数据集、Twitter/Reddit/微博等平台公开研究数据集、HuggingFace / Papers-with-Code 上的相关数据集）；
  - 真实流量 / 参与度 / 转发链数据（已发表研究的互动量、转发树、完播率；或平台公开 API 抽样，非 AI 估算）；
  - 大规模实证研究论文（peer-reviewed 或 preprint：social contagion、information cascade、meme diffusion、virality、basic reproduction number）。
- **样本量尽可能大**：优先 N ≥ 1000 的研究 / 数据集；每条证据写明 **样本量 / 数据集规模 / 观测窗口**。禁用「很多」「大量」。
- **可核查**：每条结论附 **来源（DOI / 数据集 URL / 平台+研究名）**。
- **诚实边界**：样本有偏（如仅英文 Twitter）必须显式标注，不得外推全人类。
- **检索渠道建议**：OpenAlex / Semantic Scholar / arXiv / Google Scholar / Papers-with-Code / HuggingFace Datasets / 各平台公开研究（微博、Reddit、Twitter 学术数据集）。

## 四、交付物（都放本文件夹）

| 文件 | 内容 |
|---|---|
| `synthesis.md` | 研究综述 + 对写作的可操作结论：哪些机制可写进各人群版本、怎么写、有无真实数据支撑 |
| `data-inventory.md` | 真实数据清单：名称、规模 N、来源 URL/DOI、适用哪个研究问题、有偏标注 |
| `papers/` | 关键论文引用 + 摘要笔记（能合法获取的 PDF 也放这） |
| `notes/` | 过程笔记、失败尝试、未解问题、检索式 |

> 数据集文件若体积大，不要直接塞进 git；在 `data-inventory.md` 记清来源 URL 与获取方式，必要时用 `notes/` 存元数据或小规模样本。

## 五、成功判据

- `data-inventory.md` 至少含 **10 条**带明确 N 与可核查来源的真实证据，覆盖研究问题 1–5 中至少 3 个。
- 每个研究问题都有结论，或明确标注「暂无大样本证据」。
- `synthesis.md` 给出可直接落进 `../main2/versions/` 各版本的具体写作建议（钩子类型、机制、人群差异），且每条建议标注证据等级（强 / 中 / 弱 / 无）。

---

## 六、与写作规则的接口

- 本文件夹的实证结论，是 §十三 13.3「实证数据强制要求」的落地处。
- 多人群版本（students/office-workers/insiders/structure-learners）扩写时，任何量化断言必须回指本文件夹证据。
- 研究过程中若发现正文 / 版本里某条「共鸣断言」缺乏证据，不要擅自删改书稿，只在 `notes/` 记一笔「待补证据：……」，交由写作侧处理。

---

## 七、执行要点（给执行研究的人 / Agent）

- 先建 `data-inventory.md` 骨架，边检索边填，避免证据散落。
- 每检索到一个证据，立刻记录：一句话结论 + N + 来源 + 适用问题编号。
- 优先做大样本、可复现的研究；单案例 / 访谈类证据标注为「弱」，不与大样本并列。
- 写 `synthesis.md` 时，每条写作建议都链接到 `data-inventory.md` 的具体条目。
- 遇平台数据需 API / 授权，记在 `notes/`，不要伪造数字。
