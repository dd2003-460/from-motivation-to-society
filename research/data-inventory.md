# data-inventory.md — 真实数据清单（实证证据表）

> 服务于 `research/README.md` 的 5 个研究问题。
> **硬约束**：每条必须是真实、可核查的数据（公开数据集 / 真实流量参与数据 / 大规模实证研究论文），
> 必须写明 **N（样本量或数据集规模）**、**观测窗口**、**来源（DOI / URL / 平台+研究名）**、
> **适用问题编号（Q1–Q5）**、**偏倚标注**。禁止 AI 自造例子或估算数字。
>
> 状态标记：`[已核实]` = 已通过 OpenAlex / Semantic Scholar / arXiv / 出版方页面核验元数据；
> `[待核实]` = 已定位但数字需二次确认；`[未找到]` = 检索无果（转 `notes/`）。

---

## 0. 证据等级与偏倚标注约定

| 标记 | 含义 |
|---|---|
| **等级：强** | 大样本（N≥10,000）+ 预注册或同行评审 + 可复现；或平台全量日志研究 |
| **等级：中** | N≥1,000 的观察性研究 / 多研究组合；或 N 较小但为实验设计 |
| **等级：弱** | 单案例、N<1,000 的观察研究、单平台小样本、仅实验室样本 |
| **等级：无** | 暂无大样本证据 |

| 偏倚标记 | 含义 |
|---|---|
| ⚠️**平台偏** | 单一平台（英文 Twitter / Reddit / 微博等），不可外推全人群 |
| ⚠️**样本偏** | 样本非随机（自选用户、大学生样本、WEIRD 样本） |
| ⚠️**窗口偏** | 观测窗口短或集中于单一事件期 |
| ⚠️**语言偏** | 仅单一语言语料 |
| ⚠️**度量偏** | 关键变量为算法推断（情感词典 / 分类器）而非人工标注 |
| ⚠️**历史偏** | 历史数据残缺，规模为下限估计 |
