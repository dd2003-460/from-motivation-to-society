# 作者声音 · 正反例对照

> 每个例子：BEFORE = AI/讲座腔写法（用户刚点名的"ai味"）；AFTER = 按本 skill 的手法改写的作者声音。
> 全部基于真实语料，不是凭空编的写作建议。

---

## 例 1：「不是…而是…」当节奏锤 vs 每节一次荷载论断

**BEFORE（AI v2 导论片段）**
```
这不是孤例。苏联崩溃前，几乎每一家主流智库都预测它会长期存在；
无数专家对一次次社会转折给出了事后看来荒唐的判断。
共同的失败模式不是「数据不够」，而是把描述过去和预测未来当成了同一件事。
它们不是同一件事——这是整本书要展开的论点。
```
> 问题：连续两句 "不是…而是…"，第二句还把同一对比重复一遍（"它们不是同一件事"）。这是节奏锤。

**AFTER（作者声音）**
```
你可能会说：这不过是一次意外，运气差。
没错——但看看苏联。崩溃前，几乎每家主流智库都赌它能撑很久；
一次次社会转折，专家事后看都荒唐。
共同的失败不是"数据少"，而是一个更隐蔽的错觉：把"描述过去"当成了"预测未来"。
（这一点后面会反复回来打脸，先记着。）
```
> 改动：①"你可能会说…没错"对话钩子；②"不是…而是…"只留一次、且是荷载论断；③"反复回来打脸"保留前进钩子，不重复对比。

## 例 2：抽象开场无落地 vs 读者行为预测框 + 生活类比

**BEFORE（AI v2 导论）**
```
那些最会算的人，模型里缺的不是数学，是因果。一个只记录「过去 A 和 B 同时出现」的
模型，永远分不清「A 导致 B」和「是 C 同时导致了 A 和 B」。
它能在平稳时期把历史拟合得天花乱坠，一旦环境变了就全盘崩溃。
```

**AFTER（作者声音，取自 ch1 的真实手法）**
```
那些最会算的人，模型里缺的一样东西，恰恰是他们最看不上的——因果。
\begin{tcolorbox}[colback=yellow!5, title=\textit{读者行为预测}]
现在你可能想反驳："可他们的模型在平稳年代明明很准啊。"
啊哈，我就猜到你会这么想。准，是因为那段日子没出意外；
一旦环境变了，它连"自己为什么之前准"都解释不了。
\end{tcolorbox}

生活类比：这就像一个只会背过去十年天气的人，从没学过"为什么"会下雨——
明天台风来了，他照样懵。
```
> 改动：①加"读者行为预测"snark 框接住反驳；②"生活类比"用具体画面（背天气/台风）替代"拟合得天花乱坠"的抽象陈述。

## 例 3：平滑讲座腔 vs 寄存器混搭（梗 + 自我暴露）

**BEFORE（AI v2 导论）**
```
因此全书的目标始终是：让你对一件还没发生的事，也能给出有依据的判断，
并说清「这个判断依赖哪几个因素」。这正是预测的最小单元——反事实推演。
```

**AFTER（作者声音，取自 ch1「集邮式」「狗头」式混搭）**
```
所以本书真正想给你的，不是水晶球，是一套"如果当初没有 X，今天会怎样"的推演本事。
说白了就是：面对一件还没发生的事，你也能拍着胸脯说"我看它成，是因为 A 和 B，
不是因为 C"——（示范了一下什么叫反事实推演）。
```
> 改动：①"不是水晶球"口语；②"（示范了一下…）"自我暴露旁白，正是作者原书 ch1 的招牌动作；③寄存器从高高在上降到跟朋友聊天的调。

## 例 4：模糊主体 vs 命名实体 + 硬数字

**BEFORE（AI v2 导论）**
```
苏联崩溃前，几乎每一家主流智库都预测它会长期存在；无数专家对一次次社会转折
给出了事后看来荒唐的判断。
```

**AFTER（作者声音，取自 part3 的真实写法）**
```
以苏联为例：CIA 直到 1989 年还在年报里写"体制稳定，短期内无崩溃迹象"；
同一拨人，对 2008 年次贷，标普和穆迪把一堆垃圾债评成 AAA。
```
> 改动：把"每一家主流智库""无数专家"换成**具体机构 + 具体动作 + 具体时间**。作者原书 ch「经济基础」通篇如此（梵高/比特币/猪周期/De Beers），从不说"某些机构"。

## 例 5：机械「逻辑衔接」罗列全书 vs 只指向下一节的真问题

**BEFORE（AI v2 导论·逻辑衔接）**
```
写作上有两条铁律贯穿全书：其一，每章开头都是上一章遗留的问题；
其二，每个新概念都通过「加入一个约束」导出……（接着把六部分别抽象总结一遍）
```

**AFTER（作者声音，取自 ch1 的真实逻辑衔接）**
```
人存原理告诉我们"存在者必然满足存在条件"，但它没回答：
在所有满足条件的东西里，为什么这一个活了、那一个没了？
是随机，还是某种我们还没看清的机制？这正是下一节「中性选择」要拆的。
```
> 改动：①不罗列全书结构；②只抛"下一节要解决的那个具体问题"；③用真问题收尾，不是总结。

## 记法速查（写时贴墙上）

- 钩子：`你有没有想过…` / `你可能会说…没错，但…`
- 接反驳：`读者行为预测` 框 + `啊哈，我就猜到你会这么想`
- 类比：`生活类比` / `半严谨类比` 框，必须带画面
- 落地：`命名实体 + 数字`，拒绝"某些/一般来说"
- 收尾：加粗 `关键洞见` / `核心洞见`，短句重述
- 红线：`不是…而是…` 每节 ≤ 1 次；无 snark 框、无具体案例、无意外感 = AI 味
