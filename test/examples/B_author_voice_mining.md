# B 法示例 · §1.1 一个最小的解释单元

- **适用方法**：B `author-voice-mining`。三级 role 校验 + `user_likelihood>=0.6` 过出 271 条本人原话（263812 字），产出 `voice_features.md` 与 `author-voice/SKILL.md`；把量化特征当硬约束喂给写作，产出物是可直接消费的 skill。
- **借了哪些维度**：平均句长 39.0 字、问号率 0.413、祈使率 0.513、第一人称率 0.675、连接词频率表（所以 220 / 但是 27 / 其实 26 / 不过 19，两枚低频同义换写词合计 8 次按禁用处理）、口头禅 Top10 2-gram（`一个/问题/质量/需要/模型/什么/可以/数据/结构/工具`，其中被课题词污染的前五枚不堆砌）、「否定+转折」句式 96 次 / 0.3639 每千字（限 1 处）。
- **与基线的可观察差异**（同口径实测，见第 7 节）：① 块数 9 → 17，平均句长 16.4 → 9.9 字，短轮化过头；② 论断由「本书的主张」改成「我要把它停在动机」，含第一人称的块 0/9 → 3/17；③ 破折号 11 处 → 0 处，插入语改冒号；④ 「否定+转折」句式 2 处 → 0 处，改成先肯定再转折；⑤ 排版由「正文 + box」换成 SKILL.md 的规则块 + 自检清单。论点与四群例子一个没删。

> 反面清单：语料黑名单里那四枚书面套语（AI 长回答最爱用的开场与收尾）一句都不许出现，本文也不把它们写出来当例子。这套禁令与语料黑名单同源：命中它们的段落，多半是 role 校验漏掉的 AI 长回答。

## 1. 钩子

小孩打碎了杯子。大人问：为什么碎了？因为手滑。

为什么手滑？杯子烫。为什么烫？刚倒了热水。为什么倒热水？想喝茶。为什么想喝茶？

问到第四个「为什么」，大人不耐烦了。这个不耐烦的时刻要看清：它是解释的极限，不是耐心的极限。

再往下答，出来的东西换学科了：神经递质、血糖曲线、演化史。那是别人的地盘。所以解释链必须停。停在哪，哪里就是这条链的起点。

## 2. 主张

我要把社会现象的停点放在动机（motivation）上。这是最经济的停点。

想喝茶，一个动机。它拆不下去。

它有生理基础。可再往下拆，你就滑进了神经系统：解释的对象换了，答案对不上问题。

## 3. 三件套

把「他这么做，是因为……」拆开，一共用到三件东西：

- 主体：「他」，一个会行动的单位。人、公司、乃至一个文明都算。
- 动机：「因为」后面那截，主体想要什么。
- 环境：没说出口、但永远默认的背景。杯子是烫的，茶买得到。

任何解释都要这三件。少一件，话就说不完整。

## 4. 例子

不信，看四群人每天都在做的解释：

- 学生：他考得好。动机=想上好专业；行为=刷了三千道题；环境=题目恰好练过。
- 上班族：他被提拔。动机=想升职；行为=做了关键项目；环境=正好赶上部门扩编。
- 买菜的你：菜价涨了。动机=摊贩想多赚；环境=今早下大雨，没人出摊。
- 读历史的人：王安石推新法。动机=想富国强兵；环境=新法在执行里变形。

四件事，四个领域，一副骨架：主体、动机、环境。再拆就出界，再并就含混。这就是解释的最小单元。

## 5. 反问挡回去

> 你可能会问：动机是最小单元？那动机自己从哪来？你只是把问号往下挪了一层。

诚实回答：我回答不了，本书也不假装能回答。

动机的来源（演化、生理、童年、历史）在本书边界之外。本书从动机起步，就像几何学从「点」起步：不问点是什么做的，只问点服从什么规律。

## 6. 自检（写完照抄这几问）

1. 每句 ≤40 字吗？超了就切。
2. 论断落在「我」上吗？「本书认为」不算，「我要」才算。
3. 连接词只有 所以 / 但是 / 其实 / 不过 吗？
4. 否定+转折句式超过 1 处了吗？超了删掉，改成先肯定再转折。
5. 四群人的例子都在吗？删掉一个，说服力就少一档。
6. 数字在吗？「三千道题」这种硬数字比形容词顶用。
