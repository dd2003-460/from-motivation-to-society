# G 法示例 · §1.1 一个最小的解释单元

- **适用方法**：G `ghostwrite`（公开，brianruggieri）。从 session logs 建量化 `voice-profile.md`，写邮件/报告/文章时 load 该 profile 保持一致。它是唯一明确以「写长文保持声音」为目标的工具，直接对上本书需求（一章几千字，不是几百字聊天）。
- **借了哪些维度**：段落节奏（段长分布）、句长上限、开场方式、过渡与回指（callback）、收尾前进钩子、术语首现规则、禁用清单、长文漂移点与自查频率。
- **与基线的可观察差异**（同口径实测）：① 排版由「box + itemize」改成连续散文段，只在三件套与四群例子两处保留列表；② 新增段间过渡与回指（第 8 段回指第 1 段的「第四个为什么」），基线靠 box 承担结构；③ 散文段 26–113 字，段长标准差 30.3 → 29.0，几乎没改善；profile 里写的 60–150 字下限有 4 段没守住，如实记；④ 结尾加前进钩子（下一节的次序问题），基线的钩子只在 `\paragraph*{逻辑衔接}` 里，正文没有；⑤ 「否定+转折」句式 2 处 → 0 处，破折号 11 处 → 0 处；⑥ 平均句长 16.4 → 18.0 字，是六个示例里唯一没有把句子改碎的，这正是「长文口径」的目的。论点与四群例子全留。

## voice-profile.md（写作时加载）

```text
身份：计算天体物理出身的社科作者，写给非专业读者。
节奏：段 60–150 字；句 ≤40 字（语料均值 39.0）；一段只干一件事。
开场：不铺背景，第一句就落到具体场景或对方的话上。
过渡：段间用「所以 / 但是 / 其实 / 不过」，不用书面过渡套语。
回指：每 3–4 段回指一次前面的具体词（不重复论点，只钉住那个词）。
钩子：每节结尾留一个下一节要答的问题，不许用「综上所述」收尾。
人称：论断第一人称（第一人称率 0.675）；不确定用「可能 / 应该」，不用「我猜」。
术语：首现给「中文（小写英文）」，之后只用中文；同一术语不换说法。
例子：每个抽象论断后 200 字内必须落一个具体例子，例子要带数字。
禁用：值得注意的是 / 综上所述 / 显而易见 / 毋庸置疑；破折号插入语每段 ≤1。
长文漂移点：写到第 800 字后容易变讲座腔（句子变长、被动、加抽象名词）。
自查：每 800 字停一次，读上一段，若像被错标的 AI 长回答就重写那一段。
```

## 应用结果：§1.1 重写（长文口径）

小孩打碎了杯子，大人问为什么碎了。因为手滑。为什么手滑，因为杯子烫。为什么烫，因为刚倒了热水。为什么倒热水，因为想喝茶。为什么想喝茶？

问到第四个「为什么」，大人开始不耐烦了。我要说的就是这个不耐烦的时刻。它是解释的极限，不是耐心的极限。再往下答，给出来的东西已经换了学科：神经递质、血糖曲线、演化史，那是别人的地盘。所以解释链必须停在某处，而停下来的地方，就是这条链的起点。

那对社会现象，链条该停在哪？我的答案是动机（motivation）。这是最经济的停点。想喝茶就是一个动机，它不可再拆。它有生理基础，这一点我不否认；但再拆下去，你解释的对象就从社会换成了神经系统，问题变了，答案对不上。

现在把「他这么做，是因为……」这句话正式拆开，它一共用到三件东西：

- 主体：「他」，一个会行动的单位，人、公司、乃至一个文明都算。
- 动机：「因为」后面接的东西，也就是主体想要什么。
- 环境：这句话没说出口、但永远默认的背景，比如杯子是烫的、茶是买得到的。

任何解释都需要这三件套。少一件，句子就不成立。你要是不信，看看四群互不相干的人每天都在做的解释：

- 学生：他考得好，是因为想上好专业（动机），刷了三千道题（行为），题目恰好练过（环境）。
- 上班族：他被提拔，是因为想升职（动机），做了关键项目（行为），正好赶上部门扩编（环境）。
- 买菜的你：菜价涨了，是因为摊贩想多赚（动机），今早下大雨没人出摊（环境）。
- 读历史的人：王安石推新法，是因为想富国强兵（动机），新法却在执行里变形（环境）。

四件事，四个领域，同一副骨架：主体、动机、环境。回到那个第四个「为什么」：它之所以问不下去，就是因为再往下已经凑不齐这三件了。再拆就出界，再并就含混。这就是解释的最小单元。

读到这里你大概想反驳：动机是最小单元？那动机本身从哪来，你只是把问号往下挪了一层。这个反驳是对的，我诚实回答：本书不假装能回答。动机的来源，演化、生理、童年、历史，都在本书边界之外。本书从动机开始，就像几何学从「点」开始，不解释点是什么做的，只研究点服从什么规律。
