# H 法说明 · 为什么模型微调不适合可编辑书稿

- **适用方法**：H `Digital-Self-Replica`（公开，francescobrigante）。QLoRA 微调 7B（DeepSeek-R1-Distill-Qwen-7B）模仿个人 WhatsApp 风格，产出 LoRA 检查点。
- **借了哪些维度**：本文件不做完整重写。只借它的「输出形态」当反面参照：风格全进权重，不落文本。
- **与基线的可观察差异**：见第 3 节的样例。差异不在个别词，在于产出物不可编辑、不可 diff、不可追责。
- **本沙箱状态**：无 GPU、无该仓库的 WhatsApp 语料，未实际微调。下面第 3 节的样例是我按该方法「已克隆成功」时的预期形态手写的演示，标注为演示，不冒充模型输出。

## 1. 为什么微调法对书稿不适用

1. 风格锁在权重里，改不动。书稿要能逐句改：编辑划掉一句、合著者补一个例子、作者三年后回来重写一节。LoRA 检查点是一堆浮点数，改一句话的成本是重训。
2. 不可 diff，评审失效。本仓库的流程是 `git diff` + 人读。检查点是二进制，进不了 PR 讨论，也说不清「这次改了什么」。
3. 不可解释。B/E/F/G 都能回答「为什么这句要短」：句长 39.0 字、问号率 0.413。微调只能回答「模型就这样」。写作规则没法交接给下一个 agent。
4. 论断无法追责。书里每个论断要能对回语料或文献。微调模型的句子没有来源链，出了错（术语、数字、引用）也定位不到是哪一步。
5. 术语与结构不受控。box、itemize、术语首现规则、章节钩子，这些是排版与论证结构，不是「语感」。微调只学 token 分布，学不到「本节限一处否定+转折」这类硬约束。
6. 成本与可复现门槛。要 GPU、要数据、要固定随机种子才能复现。而 B/E/F/G 的产出是一份 markdown，任何人 clone 仓库就能用。
7. 与 survey 的评级一致：H 在 `test/survey.md` 的对比表里是「可控性低 / 可解释低 / 写作适配 ★」，唯一强项是不用人工写规则。

## 2. 什么情况下它才有用

- 做一个**聊天分身**（客服、陪伴、自动回复），目标是「像」，不是「对」，不需要编辑。
- 当作**风格回归测试的对照生成器**：让它生成一段「纯语感版」，人工比对，看正式方法（B/E/F/G）漏掉了哪些个人习惯。这只是辅助，不进正文。

## 3. 样例：若它真能克隆，§1.1 会长成这样（演示，非模型输出）

> 小孩把杯子打碎了，大人问为什么碎了，说手滑，为什么手滑，说杯子烫，为什么烫，说刚倒了热水，为什么倒热水，说想喝茶，为什么想喝茶，然后大人就烦了哈哈。其实这个烦的时刻挺关键的，它是解释的极限，不是耐心的极限，再往下就是神经递质血糖曲线演化史了，那是别的学科的事。所以链条得停，停的地方就是起点。我觉得对社会现象停在动机上最省事，想喝茶就是个动机，拆不动了，它有生理基础但再拆就跑到神经系统去了，问题就换了。反正就是三件套，主体动机环境，学生考试、上班族升职、买菜涨价、王安石变法，全是这一副骨架。你要问动机从哪来，那本书不管，跟几何学从点开始一样，不问点是啥做的，只问点守什么规矩。

对照可见的失败点：

- 没有 box、没有列表，四群例子被压成一句排比，读者扫不到；
- 术语首现不给英文（motivation 消失），后文引用无锚点；
- 语气词与笑点（「哈哈」「反正就是」）进正文，书稿不能这么写；
- 没有前进钩子，本节和下一节断开；
- 想改其中任何一处，只能重训，不能在文本上动手。

这就是它评 ★ 的原因：克隆得像，但产出物不可编辑，而这本书要的恰恰是可编辑。
